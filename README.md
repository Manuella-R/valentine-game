# Cupid's Arrow - Pile Up Game

Cupid's Arrow is a simple yet addictive game where you click to hit falling hearts before they pile up and reach the middle of the screen. Designed for desktop/laptop gameplay!

## 🎮 Gameplay
- Hearts fall from the top of the screen and stack on each other
- Click on hearts to hit them and score points
- If hearts pile up to the middle of the screen, the game is over!
- Press **R** to restart after game over
- Score as many points as possible!

## 🖱️ Controls
- **Mouse Click**: Click on falling hearts to hit them
- **R Key**: Restart the game after game over
- **Close Window**: Exit the game

## 📦 Installation
### For Windows/Linux/Mac
1. Install Python 3.8 or later
2. Install Pygame:
   ```sh
   pip install pygame
   ```
3. Run the game:
   ```sh
   python main.py
   ```
   Or alternatively:
   ```sh
   python in.py
   ```

## 🎨 Customization
- **Background image**: Replace `download.jpg` with your own image
- **Heart sprites**: Add PNG images inside the `Red_Flowers` folder (optional)
- **Game difficulty**: Adjust `SPAWN_INTERVAL` in the code (lower = harder)
- **Window size**: Modify `WIDTH` and `HEIGHT` variables

## 🛠️ Requirements
- Python 3.8+
- Pygame library
